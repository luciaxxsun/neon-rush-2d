# 霓虹狂奔 2D · NEON RUSH

像素风 2D 横版跑酷小游戏，纯 HTML + Canvas 手写，**没有任何外部图片/依赖**，一个文件就能离线跑。

## 在线玩

https://luciaxxsun.github.io/neon-rush-2d/

## 本地玩

直接双击 `game.html`（或 `霓虹狂奔2D.html`，两个是同一个游戏）即可，不需要联网、不需要服务器。

## 玩法

| 按键 | 作用 |
|---|---|
| `A` `D` / `←` `→` | 左右移动 |
| `SPACE` | 跳跃 |
| `E` | 进传送门 / 进店 / 买东西 / 乘电梯 |
| `SHIFT` | 冲刺（买到靴子后） |
| `F` | 全屏 / 退出全屏 |

## 里面有什么

- **出生空岛**上下两层：下层街道 + 十家能走进去的小店，上层高架步道 + 另一排建筑，楼之间用电梯上下
- **十家小店都能走进店内**：店里自由走动，展台前按 E 直接买，柜台前按 E 开面板点着买，门口按 E 出门
- 每家店有专属陈设：便利店货架、拉面店餐桌椅、唱片行黑胶箱、花店花桶、街机厅机台……
- 中央传送门 → 中枢岛 → 5 个世界，共 **35 个跑酷挑战**
- 商品 40 件：吃的喝的是**限时效果**（45~120 秒，左上角有倒计时条），装备/义体是永久的
- 掉落规则：挑战里掉下去回出发的世界岛，世界岛掉下去回岛上，只有出生空岛掉下去才重生

## 目录

- `index.html` — 介绍页（GitHub Pages 首页）
- `game.html` / `霓虹狂奔2D.html` — 游戏本体（单文件，160KB）
- `src/` — 源码（10 个 JS 模块 + head.html 模板）
- `build_game.py` — 打包脚本，把 `src/` 拼成 `game.html`
